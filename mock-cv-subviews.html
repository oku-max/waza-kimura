カスタムリスト・14本（見本）

この形の考え方

  • リスト … どの動画を入れるか（今までどおり。手で選ぶ／条件で作る）
  • 見え方（リストの中に何個でも・名前つき） … そのリストの動画をどう絞って、どうまとめて見せるか。Notion の「ビュー」と同じ
  • カード／テーブル … 今までどおりボタンでいつでも切り替え。見え方には含めない

まとめ方は4種類（今ある情報だけ）

  • タグ（タググループごと） … タグ1〜4の枠に入っていない未使用のタググループも選べる。1本に複数付いていれば、その数だけ列に出る
  • プレイリスト・チャンネル … 動画の出どころなので動かせない
  • カスタム列（セレクト・評価だけ） … 1本に1つ

ドラッグで変わるもの

  • 動画のタグ・カスタム列の値そのものが変わる＝ほかのリスト・ライブラリにも効く（動画パネルで付け外ししたのと同じ書き込み wkSetTagValue）
  • A の列から B の列へ … A を外して B を付ける。ほかのタグは触らない（スタンディング＋後ろ重心 の動画を 後ろ重心 → 膝立ち に動かすと、スタンディング＋膝立ち）
  • 「〇〇なし」へ … 動かした列の値だけ外す／「〇〇なし」から … 付けるだけ
  • 動かした直後のトーストで取り消せる

データの持ち方（案）

リストに view.subViews = [{id, name, filter, groupBy, at}] を足すだけ（groupBy は 'tag:グループid'・'pl'・'ch'・'cf:列id'・なし）。 動画に新しい欄は作らない。見え方を消しても動画・タグは1文字も変わらない。見え方を何も作らなければ今と同じ画面。 見え方の絞り込み・まとめ方は「上書き保存」を押したときだけ覚える（v53.020 の条件リストと同じ）。端末をまたぐ同期は今のリストの同期に乗る。
