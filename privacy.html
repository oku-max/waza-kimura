2. 利用目的

  • 本サービスの提供（データの保存・複数端末間の同期）
  • AI機能（タグ提案、要約、字幕生成、翻訳、文字起こし）の提供
  • 不具合の調査および改善
  • 外部APIの利用回数の管理（1利用者あたりの上限の適用）
  • 本規約に違反する利用の防止

取得した情報を、上記の目的以外に利用することはありません。

各社のプライバシーポリシー: Google、 Anthropic、 AssemblyAI、 Cloudflare

4. YouTube API Services について

  1. 本サービスは YouTube API Services を利用しています。
  2. 本サービスを利用することにより、あなたは YouTube 利用規約 に同意したことになります。
  3. Google のプライバシーポリシーは https://policies.google.com/privacy をご参照ください。
  4. 本サービスが YouTube API Services を通じて取得する情報は、公開されている動画のメタデータ（タイトル、チャンネル名、再生時間、サムネイル、公開日）に限られます。あなたの YouTube アカウント、視聴履歴、登録チャンネルにはアクセスしません。
  5. 取得したメタデータは、あなたのライブラリ表示のためにのみ利用し、30日を超えて保持する場合は最新の内容に更新します。更新できない場合は削除します。
  6. 動画の再生は YouTube 公式の埋め込みプレーヤー（IFrame Player API）を通じて行われます。本サービスが動画を保存・配信することはありません。
  7. 本サービスによる Google データへのアクセス権は、Google アカウントのセキュリティ設定ページからいつでも取り消すことができます。

5. Google ユーザーデータの取扱い（限定利用）

本サービスによる Google API から取得した情報の使用および他アプリへの転送は、Google API サービスのユーザーデータに関するポリシー（限定利用の要件を含む）に準拠します。

具体的には、本サービスは Google Drive から取得したデータを以下のとおり取り扱います。

  • あなたが本サービスに登録した動画の再生およびサムネイル表示のためにのみ使用します。
  • 当方のサーバーに Drive のファイル内容を保存しません（再生時に中継するのみです）。
  • 広告目的で使用せず、第三者に販売しません。
  • 人間による閲覧は行いません。ただし、あなたの明示的な同意を得た場合、セキュリティ目的の場合、法令遵守のために必要な場合を除きます。
【要確認：公開前】 本サービスは現在 Google Drive の全体アクセス権限（auth/drive）を要求しています。 これは Google の「制限付きスコープ」に該当し、一般公開にあたっては Google の審査（および年次のセキュリティ評価）が必要になる場合があります。 公開範囲を確定する前に、必要最小限のスコープ（drive.file）への変更を検討してください。

6. ローカルストレージ・Cookie

本サービスは、広告目的・追跡目的の Cookie を使用しません。ブラウザのローカルストレージおよびセッションストレージを、以下の目的で使用します。

  • 表示設定（テーマ、文字サイズ、列幅など）の端末ごとの記憶
  • オフライン時および読み込み高速化のためのデータの一時保持
  • Google Drive アクセストークンの一時保持（タブを閉じると消えます）

ブラウザの設定からこれらを削除できます。削除した場合、端末ごとの表示設定は初期化されますが、クラウドに保存されたデータは失われません。

8. データの削除・エクスポート

  • エクスポート: アプリの設定画面から、登録データを書き出せます。
  • 削除: アカウントおよび全データの削除をご希望の場合は、アプリ内フィードバックまたは下記メールアドレスまでご連絡ください。合理的な期間内に削除します。
  • アクセス権の取り消し: Google アカウントのセキュリティ設定から、本サービスの権限をいつでも取り消せます。

9. 安全管理

  • 通信はすべて HTTPS で暗号化されます。
  • データは Google（Firebase）のインフラ上に保存され、利用者ごとにアクセスが分離されるよう設定されています。
  • ただし、本サービスはベータ版であり、当方は完全な安全性を保証するものではありません。機微な情報の入力はお控えください。

10. 第三者への提供

当方は、以下の場合を除き、あなたの情報を第三者に提供しません。

  • あなたの同意がある場合
  • 本ポリシー第3条に記載した、機能提供に必要な外部サービスへの送信
  • 法令に基づく開示請求があった場合

あなたのデータを広告目的で販売・共有することはありません。

11. 本ポリシーの変更

本ポリシーは必要に応じて変更します。重要な変更を行う場合は、本サービス上での掲示その他の適切な方法により告知します。

12. お問い合わせ

個人情報の取扱いに関するお問い合わせは、アプリ内のフィードバック機能、または okujournal@gmail.com までお願いします。
