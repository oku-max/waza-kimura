# Google Drive のスコープをどうするか（調査 / 2026-08-13）

一般公開の前に決めないといけないことのうち、**いちばん判断が重い**もの。
実装より先に、方針を選ぶ必要がある。

---

## 1. 何が問題か

アプリは Google Drive の**全体アクセス権限**を要求している。

```js
// js/gdrive.js:10
const GD_SCOPE = 'https://www.googleapis.com/auth/drive';
```

`auth/drive` は Google の**制限付きスコープ（restricted scope）**にあたる。
一般公開するには、通常の OAuth 審査に加えて、
**Google が認定した第三者機関によるセキュリティ評価（CASA）**が必要になる。

さらに条件が悪い方に効いている。CASA が必要になるのは
「制限付きスコープのデータを、自社サーバーに保存する、または
サーバーを経由して転送する」場合。**このアプリは該当する。**

| 経路 | やっていること |
|---|---|
| `/api/drive` | Drive の動画本体を Cloudflare Worker 経由でストリーミング |
| `/api/ai-summary` | Drive の動画を Worker 経由で Gemini に渡す |
| `/api/asr-src` | Drive の動画を AssemblyAI に取りに来させる |

3つとも「サーバーを経由して制限付きスコープのデータを転送」に当たる。

### 費用と期間

- CASA は**年1回**の再評価が必要（前回の Letter of Validation の発行日から12か月）
- 費用は評価機関とティアによる。安いところで**年 $540 程度**、
  上のティアだと数千ドル規模になる報告がある
- 審査そのものにも数週間〜数か月かかる

**個人の副業プロジェクトで毎年払い続ける前提としては重い。**

私からは確認できない。Google Cloud Console を見てほしい。

**APIとサービス → OAuth 同意画面**

- [ ] 公開ステータスは「テスト」か「本番」か
- [ ] 「本番」の場合、審査（verification）は通っているか
- [ ] 登録されているスコープの一覧に `auth/drive` が入っているか

判断はここで分かれる。

| 現状 | 意味 |
|---|---|
| **テスト** | テストユーザー100人まで。招待制ならしばらく持つが、**リフレッシュトークンが7日で切れる**ので、週1で再ログインが必要になる（体験が悪い） |
| **本番・未審査** | 「確認されていないアプリ」の警告画面が出る。制限付きスコープには人数上限がかかる |
| **本番・審査済み** | 既に CASA を通しているということ。この文書の心配は不要（ただし年次の再評価は来る） |

## 3. 選択肢

### 案A: `drive.file` に変える（推奨）

`https://www.googleapis.com/auth/drive.file` は**制限付きではない**。
CASA が要らなくなる。年間費用ゼロ。

権限の範囲は「**アプリが作ったファイル**」と「**ユーザーが明示的に選んだファイル**」だけ。
選択には **Google Picker API** を使う。

#### 何が動かなくなるか

現在の Drive まわりの機能を全部洗い出した結果:

| 機能 | 実装箇所 | `drive.file` で |
|---|---|---|
| フォルダ一覧の取得 | `js/gdrive.js:180 listFolder` | ❌ **動かない** |
| フォルダの再帰走査（深さ3） | `js/gdrive.js:429 scanFolder` | ❌ **動かない** |
| フォルダブラウザUI | `js/gdrive.js:603 gdOpenBrowser` | ❌ **作り直し** |
| フォルダのお気に入り | `js/gdrive.js:594 gdFavToggle` | ❌ 意味が無くなる |
| 選んだ動画の再生 | `/api/drive` | ✅ 動く |
| サムネイル取得 | `js/gdrive.js:338` | ✅ 動く（選択済みファイル） |
| MP4から長さを取得 | `js/gdrive.js:247` | ✅ 動く（同上） |
| 字幕ファイルの新規作成 | `js/vpanel.js:2866` | ✅ 動く（アプリが作ったファイル） |
| 既存の字幕ファイルの更新 | `js/gdrive.js:1180` | ⚠️ **要検証**（下記） |

**核心はここ**: いまの取り込み体験は「フォルダを丸ごと走査して、
中の動画を一括で取り込む」という形。`drive.file` ではこれができない。

#### 代わりにどうするか

Google Picker は**複数選択に対応していて、フォルダの中も辿れる**。
つまり「Googleの画面で、フォルダを開いて、動画を複数選んで一括追加」はできる。

失うのは主に次の2つ:
1. **フォルダを丸ごと自動で取り込む**（1つずつ選ぶ必要がある。ただし全選択は可能）
2. **後からフォルダに足した動画が自動で見つかる**（再度Pickerで選び直す必要がある）

#### 要検証（私では確認できないこと）

- ⚠️ **移行前に作った字幕ファイル**（`auth/drive` で作成）が、
  `drive.file` に切り替えた後も更新できるか。
  ファイル単位の許可は残るという理解だが、スコープ変更をまたぐ挙動は
  実際に試さないと分からない。**移行前に必ず1本で試すこと。**
- ⚠️ 既存ユーザーは再認可が必要になる。既に登録済みの Drive 動画が
  再生できなくなる可能性がある（Pickerで選び直しが要るかもしれない）。
  **これは既存データの体験を壊すので、移行手順を設計する必要がある。**

#### 作業量のざっくり

- Google Picker の組み込み（`gapi.load('picker')`、ビルダー、コールバック）
- `switchImportTab` の Drive タブを Picker 起動に置き換え
- `gdOpenBrowser` / `scanFolder` / `listFolder` / `gdFavToggle` の撤去または無効化
- 既存ユーザー向けの移行導線（「Driveの動画を選び直してください」）
- `terms.html` / `privacy.html` のスコープ記述の更新

**中規模。1〜2日の作業＋検証。** ただし年間費用と年次審査から解放される。

### 案B: `auth/drive` のまま CASA を通す

- 費用: 年 $540〜数千ドル
- 期間: 数週間〜数か月
- 毎年やり直し
- 機能は今のまま。ユーザー体験は最良

**「Driveのフォルダ丸ごと取り込み」がこのアプリの決定的な価値なら、この選択もありうる。**
ただし、無料で公開しているアプリに毎年払い続けられるかは別問題。

### 案C: Drive 対応をやめる

YouTube と Vimeo だけにする。
CASA も Picker も不要になり、いちばん単純。

ただし「自分が買った教則（DVDやダウンロード購入したもの）を
Drive に置いて管理する」という使い方は、
柔術の教則という領域ではかなり本質的な気がする。
**オーナー自身がこの機能をどれくらい使っているかで判断が変わる。**

### 案D: 当面は招待制100人以内（テストモード）で運用する

判断を先送りできる。ただし**リフレッシュトークンが7日で切れる**ため、
週1で再ログインが必要になり、体験が明確に悪い。
「50〜100人の招待制で始める」という当初の方針とは相性がいいが、
週1再ログインを許容できるかは要判断。

## 4. 私の見立て

**案A（`drive.file` + Picker）を推す。**

理由:
1. 年間費用と年次審査から完全に解放される。個人プロジェクトではこれが決定的
2. 失う機能は「フォルダ丸ごと自動取り込み」だけ。
   Picker の複数選択で、体験の劣化は思ったより小さい
3. **副次的な効果が大きい**: `/api/drive` `/api/ai-summary` `/api/asr-src` が
   「制限付きスコープのデータをサーバー経由で転送している」という
   一番説明しづらい状態が解消される。プライバシーポリシーも書きやすくなる
4. YouTube API の増枠審査でも、要求スコープが小さいほど印象がいい

**ただし、まず §2 の確認をしてほしい。**
既に本番・審査済みなら、この話は全部不要になる。

---

## 5. やるとしたらの順番

1. Google Cloud Console で現状を確認（§2）
2. 既存の字幕ファイルが `drive.file` で更新できるか、1本で試す
3. Picker を組み込み、既存のフォルダブラウザと**並行**で動かす（後戻りできる形）
4. 自分のアカウントで通しで検証
5. 既存ユーザー向けの移行導線を作る
6. スコープを切り替え、`terms.html` / `privacy.html` を更新
